# Pata & Cia 🐾

Loja virtual demonstrativa de produtos para cães e gatos, feita com HTML, CSS e JavaScript puro.

## Como executar
Abra o arquivo `index.html` no navegador. Não precisa instalar dependências.

## Recursos
- Layout responsivo para celular e computador.
- Vitrine de produtos com filtros por categoria.
- Carrinho com alteração de quantidades e cálculo automático.
- Finalização de pedido pelo WhatsApp (abre uma conversa com o resumo).
- Formulário demonstrativo de novidades.

## Personalização
Edite os produtos, preços e imagens em `assets/js/app.js`. Para configurar o WhatsApp da loja, altere o endereço `https://wa.me/?text=` no evento de finalização e informe o número no formato internacional.

> Projeto de demonstração: preços, produtos, imagens e avaliações são ilustrativos. Não há gateway de pagamento nem processamento real de pedidos.
